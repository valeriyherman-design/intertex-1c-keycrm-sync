# Сборка обработки ИнтеграцияKeyCRM.epf

**Для:** специалист 1С · **База:** УТП для Украины 1.2.35.1, платформа 8.3.18
**Время сборки:** ~10 минут (без проверки меток) · Работать ТОЛЬКО на тестовой копии.

## 1. Сборка .epf из исходника

1. Конфигуратор → Файл → Новый → **Внешняя обработка**.
2. Имя: `ИнтеграцияKeyCRM`.
3. Открыть **модуль объекта** и вставить содержимое файла
   [`ИнтеграцияKeyCRM_МодульОбъекта.bsl`](ИнтеграцияKeyCRM_МодульОбъекта.bsl) целиком.
4. Сохранить как `ИнтеграцияKeyCRM.epf`.
5. Синтаксическая проверка (Ctrl+F7) — устранить ошибки имён метаданных (см. п.2).

## 2. Обязательная проверка меток `// ПРОВЕРИТЬ(УТП):`

Модуль написан по типовым именам линейки УТ 10.3/УТП. В файле ~15 меток —
каждую сверить с фактической конфигурацией:

| Область | Что проверить |
|---|---|
| Склады | имя справочника `Склады` |
| Каталог | реквизит `ЕдиницаХраненияОстатков`; регистр `Штрихкоды` (Владелец, Характеристика, Штрихкод); регистр `ЦеныНоменклатуры` (есть ли измерение Характеристика) |
| Остатки | регистры `ТоварыНаСкладах`, `ТоварыВРезервеНаСкладах`, измерение Характеристика |
| Контрагент | обязательные реквизиты; регистр `КонтактнаяИнформация`; процедура записи КИ (`ЗаписатьКонтактнуюИнформацию` — заполнить по типовым процедурам базы) |
| Заказ | обязательные реквизиты `ЗаказПокупателя` (Организация, Договор, ВалютаДокумента, ТипЦен); колонка характеристики в ТЧ; способ авторезервирования (Размещение / АвтоРезервирование) |
| Реализация | `Заполнить(ЗаказСсылка)` на основании; вид операции |
| Возврат | заполнение на основании реализации; пересчёт сумм при частичном возврате |
| Оплата | `ПриходныйКассовыйОрдер`: ВидОперации, Касса, ТЧ РасшифровкаПлатежа |
| Внешние ID | план видов характеристик `СвойстваОбъектов` + регистр `ЗначенияСвойствОбъектов` (механизм хранения ID KeyCRM без изменения конфигурации) |
| Перемещения | документ `ПеремещениеТоваров`, реквизиты СкладОтправитель/СкладПолучатель |

## 3. Проверка работы через COM (с машины сервиса)

```powershell
# Один раз: регистрация COM-коннектора платформы (от администратора)
regsvr32 "C:\Program Files\1cv8\8.3.18.1334\bin\comcntr.dll"
```

Тест из PowerShell:

```powershell
$connector = New-Object -ComObject "V83.COMConnector"
$conn = $connector.Connect('File="D:\ALMITS\01_INTERTEX\ITX_UTP_ТЕСТ";Usr="ИнтеграцияKeyCRM";Pwd="***"')
$proc = $conn.ВнешниеОбработки.Создать("D:\Integration\ИнтеграцияKeyCRM.epf")
$proc.ВыполнитьОперацию("health", "{}")
# Ожидаемо: {"success":true,"data":{"status":"ok","config":"...","time":"..."}}
$proc.ВыполнитьОперацию("warehouses", "{}")
# Ожидаемо: 6 складов с guid/code/name
```

> Если `ВнешниеОбработки.Создать` требует второй параметр безопасного режима —
> `Создать(Путь, Ложь)` (зависит от настроек безопасности базы).

## 4. Пользователь интеграции

Создать пользователя `ИнтеграцияKeyCRM` с минимальными правами (см.
`handover-1c/08_TASK_FOR_1C_SPECIALIST.md`, Задача 3): чтение номенклатуры/складов/
цен/остатков; создание и изменение Контрагентов, ЗаказовПокупателя, Реализаций,
Возвратов, ПКО; без административных прав.

## 5. Порядок операций и коды ошибок

Полный контракт: `handover-1c/05_API_CONTRACT.md`. Кратко:

| Операция | Что делает | Идемпотентность |
|---|---|---|
| health | версия конфигурации | — |
| warehouses | список складов | — |
| products | каталог+варианты+штрихкоды+цены (постранично) | — |
| stocks | остатки/резервы по складу | — |
| upsert_customer | поиск (KeyCRM ID → телефон → email) или создание | по buyer id |
| upsert_order | создать/обновить ЗаказПокупателя | по order id |
| reserve | проверка доступности ВСЕХ позиций → проведение с резервом | повтор = текущие остатки |
| unreserve | отмена проведения заказа | повтор = успех |
| ship | Реализация на основании + проведение | повтор = тот же документ |
| create_return | Возврат на основании реализации (реализация не трогается) | по заказу |
| register_payment | ПКО по заказу | по payment id |
| order_state | состояние всех документов по заказу | — |
| transfers | проведённые перемещения с даты | — |

Все ошибки возвращаются JSON-конвертом `{"success":false,"error":{code,message,retryable,details}}` —
исключений наружу через COM не выбрасывается (кроме падения самого соединения).
