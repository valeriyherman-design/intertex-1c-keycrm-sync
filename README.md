# intertex-1c-keycrm-sync

Интеграционный сервис **1С ↔ KeyCRM** (IntertexSync, .NET) для TM Intertex.

## Назначение
Весь ежедневный цикл работы менеджеров, удалённых сотрудников и сборщиков проходит через **KeyCRM**, без ручного дублирования заказов, клиентов, товаров, счетов и данных в **1С**. 1С остаётся внутренним учётным ядром (склад + финансы); сотрудники не заходят в 1С для обычной обработки заказа.

Middleware синхронизирует: остатки, заказы, резервы, реализацию, отмену, оплату, номенклатуру и штрихкоды.

## Текущий статус
Сквозной цикл заказа (резерв / реализация / отмена / оплата) реализован и протестирован (56/56, E2E на живом KeyCRM). Боевой запуск «на паузе» за гейтом сопоставления штрихкодов и получением доступа к 1С заказчика (1С 8.3.18, 64-бит, файловая база). Актуальные детали — в `PROJECT_STATUS.md`, `BLOCKERS.md`, `RISKS.md`.

## Структура
- `src/` — C#: `IntertexSync.Core`, `IntertexSync.Infrastructure`, `IntertexSync.Service`.
- `tests/IntertexSync.Tests` — модульные и интеграционные тесты.
- `onec/` — модуль 1С (.bsl) и инструкция сборки.
- `docs/` — аудит системы, mapping сущностей, целевой workflow, анализ данных 1С, ограничения KeyCRM, `keycrm-ui-audit/` (скриншоты + JSON интерфейса).
- `handover-1c/` — полный пакет для 1С-специалиста: обзор, окружение, объекты, order flow, API-контракт (`openapi-1c-integration.yaml`), mapping-таблицы, установка, диагностика, откат, чек-лист приёмки.
- `deploy/` — self-contained сборка win-x64, конфиг, шаблон секретов, `install-service.ps1`.
- Статус-файлы: `PROJECT_STATUS.md`, `BACKLOG.md`, `BLOCKERS.md`, `DECISIONS.md`, `RISKS.md`, `TEST_STATUS.md`, `HANDOVER_STATUS.md`, `CHANGELOG.md`.

## Как запустить
```
dotnet build IntertexSync.sln
dotnet test
```
Реальные доступы — в `secrets.json` (в `.gitignore`, НЕ коммитить). В репозитории только `deploy/secrets.example.json` с плейсхолдерами.

## Зависимости
.NET SDK (см. `IntertexSync.sln`), доступ к API KeyCRM, среда 1С 8.3.18 на стороне заказчика.

## Безопасность
Не коммитить реальные ключи KeyCRM/1С, строки подключения, `secrets.json`. Не подключаться к боевым KeyCRM/1С без явного подтверждения.
