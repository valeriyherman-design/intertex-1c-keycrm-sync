# CLAUDE.md — intertex-1c-keycrm-sync

Постоянная инструкция для Claude. У проекта уже есть богатая документация — используй её как источник правды.

## Цель проекта
Интеграция **1С ↔ KeyCRM** (сервис IntertexSync, .NET): обмен заказами, статусами, остатками, штрихкодами; синхронизация номенклатуры и продаж.

## Бизнес-контекст
Заказчик — Intertex. Площадка: сервер заказчика, 1С 8.3.18 (64-бит, файловая база), интернет до KeyCRM. Проект передаётся 1С-специалисту (см. `handover-1c/`).

## Где что лежит (изучить перед изменениями)
- `docs/` — аудит системы, mapping сущностей, целевой workflow, анализ данных 1С, ограничения KeyCRM.
- `handover-1c/` — полный пакет для 1С-специалиста: обзор, окружение, объекты, order flow, API-контракт (`openapi-1c-integration.yaml`), mapping-таблицы, установка, диагностика, откат, чек-лист приёмки.
- `src/` — C#: `IntertexSync.Core`, `IntertexSync.Infrastructure`, `IntertexSync.Service`.
- `tests/` — `IntertexSync.Tests`.
- `onec/` — модуль 1С (.bsl) и инструкция сборки.
- Статусы: `PROJECT_STATUS.md`, `BLOCKERS.md`, `RISKS.md`, `DECISIONS.md`, `BACKLOG.md`, `TEST_STATUS.md`, `HANDOVER_STATUS.md`.

## Правила работы
1. Сначала прочитай `PROJECT_STATUS.md`, `DECISIONS.md`, `BLOCKERS.md`, затем меняй.
2. Изменения покрывай тестами (`dotnet test`).
3. Небольшие логические коммиты (стиль истории уже задан — продолжай его).
4. Решения фиксируй в `DECISIONS.md`.

## Команды
```
dotnet build IntertexSync.sln
dotnet test
```
Публикация self-contained win-x64 — см. `deploy/` (пакет уже собирался).

## Требования безопасности
- Реальные секреты — в `secrets.json` (в `.gitignore`), НЕ коммитить. В репозитории только `deploy/secrets.example.json` (плейсхолдеры).
- Не подключаться к реальной базе 1С и боевому KeyCRM без явного подтверждения.

## Запрещено
Изменение боевых данных 1С/KeyCRM без подтверждения; force push; коммит реальных секретов; переписывание готовой истории (22 коммита).

## Критерии завершения
Сборка и тесты зелёные, изменения отражены в `PROJECT_STATUS.md`/`CHANGELOG.md`, при необходимости обновлён пакет передачи.

Открой репозиторий → `CLAUDE.md` → `PROJECT_STATUS.md` → `BACKLOG.md`.
