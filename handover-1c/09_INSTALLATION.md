# 09. Инструкция установки

Порядок для пилота на **тестовом** контуре. У каждого шага — ожидаемый результат.
Установщик Windows (`.exe`) — этап 7 (пока установка ручная/скриптом).

## Предусловия
- Windows-машина с доступом к базе 1С (COM), .NET 8 Runtime, исходящий HTTPS к
  `openapi.keycrm.app`.
- Собранная `ИнтеграцияKeyCRM.epf` (Задача 2 из `08_TASK…`).
- Пользователь 1С «ИнтеграцияKeyCRM» с правами (Задача 3).

## Ключевые переключатели безопасности
- `StockSync:DryRun` и `OrderSync:DryRun` — **по умолчанию `true`** (репетиция без записи
  в живой KeyCRM / X-Dry-Run в 1С). В бой переводить осознанно, по одному контуру.
- Для боевой записи остатков обязателен непустой `StockSync:Active1CWarehouseGuids`
  (6 мест) и валидный `KeyCrmWarehouseId`; для заказов — `OrderSync:DefaultWarehouseGuid`.

## Обновление сервиса
- Остановить службу → заменить файлы → запустить. Служебная БД (`data/*.db`, очередь,
  снапшоты, соответствия) сохраняется. Ручного восстановления не требуется.
